# Superstore Return Rate Analysis Project
## The purpose of this analysis project was to determine the causes and potential solutions to a growing product return rate at the Superstore chain. 
## Data was provided as an Excel doc with 3 tables, 2 of which were used for the main analysis, Orders and Returns.
## Data was analyzed using various comparisons to determine patterns based on the available information in the data set. 
## Based on the emerging patterns, conclusions and recommended actions were identified and presented in a Tableau story. 
## Tools used
### Tableau, Excel
## Key Insights
### It was determined that there are specific underperforming product subcategories pushing the return rate up. 
### Geography played a role with the highest return rates on the west coast. 
### A decided seasonal trend was identified with a very large spike in return rates for products shipped in September.
### Specific customers showed very high return rates corresponding directly with order volume. 
## Reccomendations
### Discontinuation of the 3 top underperforming subcategories. 
### Review of operations and fulfillment practices at west coast DCs
### Further investigation into the large seasonal spike including frank discussions with operations managers and reasons for returns,
### Structured customer outreach program to understand high return rates and a thorough review of the existing return policy.
